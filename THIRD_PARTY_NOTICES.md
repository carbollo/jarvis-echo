# Componentes de terceros

Jarvis Echo incluye estos componentes, todos con licencias libres que permiten redistribuirlos:

| Componente | Uso en la app | Licencia |
|---|---|---|
| [Vosk](https://github.com/alphacep/vosk-api) (`com.alphacephei:vosk-android`) | Reconocimiento de voz sin conexión | Apache 2.0 |
| [vosk-model-small-es-0.42](https://alphacephei.com/vosk/models) | Modelo de español para Vosk | Apache 2.0 |
| [Pico TTS](https://android.googlesource.com/platform/external/svox/) (SVOX AG, AOSP) | Voz de Jarvis en español | Apache 2.0 |
| [JNA](https://github.com/java-native-access/jna) | Acceso de Vosk a su librería nativa | Apache 2.0 / LGPL 2.1 |
| [OkHttp](https://square.github.io/okhttp/) | Conexión con el relay | Apache 2.0 |
| [Kotlin](https://kotlinlang.org/), [kotlinx.coroutines](https://github.com/Kotlin/kotlinx.coroutines) | Lenguaje y concurrencia | Apache 2.0 |
| [AndroidX / Jetpack Compose](https://developer.android.com/jetpack/androidx) | Interfaz | Apache 2.0 |
